## EL.PSY.CONGROO.
未来游戏研究所（Future Game Lab） 成立于 2026 年 4 月，是一个以游戏开发为核心，致力于原创同人游戏创作的社团。  
我们汇聚了来自五湖四海、因热爱而相识的创作者，以线上协作、兴趣驱动的方式共同探索游戏创作的无限可能。  
在通往未来的道路上，我们始终秉持理想、热爱与尊重的共同信念，相信创作的力量，也珍视每一份因第九艺术而产生的联结。
